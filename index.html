// About

A bit about me.

I'm focusing as a full-stack web developer — building end-to-end products where the interface, the API, and the data model all pull in the same direction.

I work across the stack: HTML, CSS, and the precise bits of JavaScript on the front; servers, data, and integrations on the back. I spend real time on the basics — typography, spacing, motion, clean endpoints — because that's where the perceived quality of a product comes from.

Right now I'm developing the RAG system inside CasePoint — built on FastAPI — the retrieval and grounding layer that turns documents into answers you can trace back to a source. Outside that, I also work with Laravel and Tailwind CSS. It's where I put the full-stack focus to work: AI that supports real workflows without getting in the user's way.
