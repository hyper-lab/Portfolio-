# Portfolio

My personal developer portfolio — built with plain HTML, CSS, and JavaScript and hosted on GitHub Pages.

## Local preview

Just open `index.html` in your browser. No build step required.

## Deploy

This repo is published with **GitHub Pages**. Pushes to `main` redeploy the site automatically.

## Structure

- `index.html` — page content
- `styles.css` — styling and theme variables
- `script.js` — theme toggle and small interactions
